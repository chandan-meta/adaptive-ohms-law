## Fullscreen release

The web template adds a 44×44 px fullscreen button in the bottom-left corner, respecting device safe areas. It follows the Amber & Ink colors and uses an inline SVG. The button appears after loading, requests fullscreen on the page so the exit control remains visible, and updates its icon, accessible name and pressed state when fullscreen changes or Esc exits. Unsupported browsers keep it hidden; a denied request leaves it available for retry.

`node Tools/test_webgl_template.cjs` passes readiness, enter/exit, browser-exit state, standard/prefixed API, unsupported and rejected-request checks.
