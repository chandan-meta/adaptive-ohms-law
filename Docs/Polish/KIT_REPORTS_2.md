How it works:
- CalloutLayer is created lazily by `CalloutLayer.Instance` (called from the SceneDirector cue cases) as a stretched rect "Callouts" under `ModuleFlow.Instance.transform.Find("SafeArea")`, set as FIRST sibling so Subtitles / Controls / Ask Wattson / prompt / MCQ draw over it; CanvasGroup blocksRaycasts=false. It persists with ModuleFlow; panels are culled when their CalloutDef (or VFX source object) is destroyed with the scene, and cue-driven VFX panels of an unloaded scene fade out (SceneManager.sceneUnloaded).
